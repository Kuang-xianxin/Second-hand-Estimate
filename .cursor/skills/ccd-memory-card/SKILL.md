### 奥林巴斯 xD 卡套（MASD-1）兼容相机

#### 什么是 MASD-1 卡套？

MASD-1 是奥林巴斯官方推出的 **microSD/TF 卡转 xD 卡适配器**（俗称"xD 卡套"）。它可以让原本只支持 xD 卡的相机使用廉价的 microSD 卡。

- **外观**：黄色塑料薄片，形状与 xD 卡相同，内部插 microSD 卡使用
- **价格**：淘宝约 2-10 元人民币，全新大量批发约 2-5 元
- **购买渠道**：淘宝/闲鱼搜索"MASD-1"或"xD卡套"
- **工作原理**：将 microSD 卡插入卡套，卡套插入相机卡槽，相机识别为 xD 卡
- **使用限制**：
  - 全景功能不可用（标注 ⚠️ 的型号）
  - 部分型号使用 4GB+ microSDHC 卡需固件 1.1 以上（否则可能损坏卡）
  - 单次录像最长 29 分钟
  - 卡套形状特殊，无法放入标准 xD 读卡器，必须用相机 USB 或取出 microSD 卡读卡

#### 为什么这个分类重要？

对于 MASD-1 兼容机型，**xD 卡捆绑价值大幅降低**：

| 情况 | 估价影响 |
|------|----------|
| MASD-1 兼容机型带 xD 卡 | 卡价值按正常 xD 估价，但需标注"可用卡套替代" |
| MASD-1 兼容机型带 microSD 卡 + 卡套 | microSD 卡不值钱，估价时卡价值几乎为零 |
| 非 MASD-1 兼容机型带 xD 卡 | xD 卡稀缺溢价明显，估价加成更高 |

## 六、快速判断流程

1. **先看品牌** — 佳能/尼康/索尼/松下/卡西欧 = SD 或 MS，非 xD
2. **富士/奥林巴斯** — 查上表确认具体型号的切换时间点
3. **看标题提到内存卡** — "带卡"/"含卡"可加卡价值，"单机"/"不含卡"不加
4. **判断卡容量** — 有描述按表查价，无描述按 128-256MB 估算
5. **判断是否是 MASD-1 兼容机型** — 如果是奥林巴斯 μ/Stylus/FE/SP 型号，先查是否在 MASD-1 兼容列表中
   - **是 MASD-1 兼容**：xD 卡加成打 6-7 折，因为买家可用 2-10 元卡套替代
   - **是富士机型**：xD 卡按原价加成，无卡套替代方案
6. **看是否带卡套** — 带卡套+microSD 的奥林巴斯相机，**不加卡价值**
